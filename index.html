为什么用它

不装 openpyxl / pandas，只用标准库读写 xlsx（zipfile + xml 最小实现），双击即跑、随处可分发。

✅ .xlsx 与 .csv 混合读写 ✅ 金额按数值比较（100 = 100.00） ✅ 输出可被 Excel / WPS 直接打开 ✅ 单文件可独立分发 ✅ 命令行一行出结果

01多表合并 merge

多个文件堆叠成一张表，表头自动并集，可按主键去重并标注来源。

python deliver.py merge a.csv b.csv c.xlsx -o 合并结果.xlsx --key 订单号 --dedup

02数据清洗 clean

去空格、删空行、按列去重、空值填充。

python deliver.py clean 脏表.csv -o 清洗结果.xlsx --dedup --key 订单号,手机号

03透视汇总 pivot

按维度分组做 sum / count / avg / max / min 聚合。

python deliver.py pivot 表.csv -o 透视.xlsx --by 城市 --agg 金额:sum:金额合计 金额:count:笔数

输入（按城市）

城市金额
上海100
北京200
上海150

输出（透视后）

城市金额合计
上海250
北京200

04按列拆分 split

一张总表按某列自动拆成多个文件，文件名即该列的值。

python deliver.py split 总表.xlsx --by 城市 --outdir 拆分结果 --xlsx

05双表对账 recon

按主键逐行比对，输出三张结果：仅在 A / 仅在 B / 数值不一致（精确到单元格）。

python deliver.py recon A.xlsx B.xlsx --key 订单号 --outdir 核对结果 --xlsx
结果文件含义示例
1_仅在表A.xlsxA 有 B 无2 行
2_仅在表B.xlsxB 有 A 无1 行
3_数值不一致.xlsx主键同但内容异0 行
