# 闲鱼发布指南（照做即可，预计 20 分钟发完 6 个商品）

## 前置（1 次）
1. 手机装「闲鱼」App，用支付宝账号登录（收款走支付宝，即时到账）。
2. 实名认证完成（卖虚拟服务需要，认证后才能发布）。

## 每个商品发布步骤（每个约 3 分钟）
1. 打开对应 `0X_*.txt`，复制【标题】整行 → 粘到闲鱼「卖闲置」的标题框。
2. 复制【描述】整段 → 粘到描述框。
3. 价格：按文件里写的档位填（前 3 单建议先填**半价**冲销量和评价，有评价后改回原价）。
4. 发货方式：选「无需物流 / 虚拟商品」。
5. 分类选「服务 / 技能服务 / 其他技能」或「办公文教」。
6. 点发布。

## 发布顺序建议（流量最大化）
先发 **01 合并**（引流最高频）→ **04 对账**（单价最高）→ 02/03 → 05/06。
前 3 单半价，评价起来后改回原价。

## 接单后操作流程（你已经有的工具）
```
cd hustle
python deliver.py info   客户文件.csv      # 先出体检报告，确认再拍
python deliver.py merge  a.csv b.csv -o 合并结果.xlsx --key 订单号 --dedup
python deliver.py clean  脏表.csv   -o 清洗结果.xlsx --dedup
python deliver.py pivot  表.csv     -o 透视.xlsx --by 城市 --agg 金额:sum:金额合计
python deliver.py split  总表.csv   --by 城市 --outdir 拆分结果 --xlsx
python deliver.py recon  A.csv B.csv --key 订单号 --outdir 核对结果 --xlsx
```
交付 xlsx 文件本身 + 两分钟说明，**不要丢 .py 给非技术客户**。

## 红线（绝不接）
- ❌ 爬虫抓个人信息 / 爬付费内容 / 破解
- ❌ 需要登录他人账号的流程
- ❌ 需求含糊说不清的——用 `hustle/SCOPE.md` 逼清边界，否则必返工
- ✅ 大额（>500 元）走闲鱼担保交易，别私下转账

## 日常维护
每天**擦亮**商品（早晚各一次，重回前排）；需求方通常同时问多人，**5 分钟内回复者得单**。
