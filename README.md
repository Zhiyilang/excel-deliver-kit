## 为什么是零依赖

客户机器环境不可控。任何 `pip install pandas openpyxl` 都可能因为网络、权限、Python 版本失败，
直接导致交付卡死。本工具自己实现了 xlsx 的读写（ZIP + XML），
**拷过去就能跑**，交付不会因为环境问题翻车。

引擎来自三个自研 kit：
- `excel_merge_kit` — 读 `.xlsx`/`.csv`、写真实 `.xlsx`
- `excel_pivot_kit` — 分组聚合
- `excel_clean_kit` — 清洗规则

## 六个命令

| 命令 | 干什么 | 典型场景 |
|---|---|---|
| `info` | 数据体检（行数/空值/重复/数值列） | 接单前估价、给客户看问题严重性 |
| `merge` | 多表合并（可去重、带来源标注） | 月结合并十几张门店报表 |
| `clean` | 清洗（去空格/空行/去重/填充） | 系统导出的脏表 |
| `pivot` | 分组汇总 | 按区域/部门统计 |
| `split` | 按列拆成多个文件 | 总表按城市发给分公司 |
| `recon` | **双表核对**，找出差异 | 财务对账、流水核对、盘点核对 |

## 用法

```bash
# 1. 先看数据再报价
python deliver.py info 客户表.xlsx

# 2. 多表合并（按订单号去重）
python deliver.py merge a.xlsx b.xlsx c.csv -o 合并.xlsx --key 订单号 --dedup

# 3. 清洗（去空格、去空行、空值填 0）
python deliver.py clean 脏表.xlsx -o 干净表.xlsx --fill 0

# 4. 汇总（按区域统计金额合计和笔数）
python deliver.py pivot 总表.xlsx -o 汇总.xlsx --by 区域 \
    --agg 金额:sum:金额合计 订单号:count:笔数

# 5. 拆分（按城市拆成多个文件）
python deliver.py split 总表.xlsx --by 城市 --outdir ./拆分

# 6. 对账（两张表按订单号比对，输出差异明细）
python deliver.py recon 我方.xlsx 对方.xlsx --key 订单号 --outdir ./核对
```

聚合函数：`sum` / `count` / `avg` / `max` / `min`

## `recon` 输出什么

对账是本工具最有价值的能力。它会输出三张表：

1. `1_仅在表A` — 只有我方有的记录
2. `2_仅在表B` — 只有对方有的记录
3. `3_数值不一致` — 主键对得上、但内容不同的记录，精确到
   **哪个主键、哪一列、表A是什么值、表B是什么值**

金额按**数值**比较（`100` 与 `100.00` 视为一致），不会被单元格格式坑。

## 设计原则

- **不静默吞错误**：文件不存在、列名不存在、聚合函数写错，都明确报错并给出实际列名。
- **列名容错**：`--by` 列不存在时提示实际有哪些列，而不是抛异常。
- **数字识别**：支持 `¥`、千分位逗号、百分号，`100` / `1,000` / `¥100` 都能算。
- **文件名安全**：拆分出的文件名自动过滤 Windows 非法字符。
